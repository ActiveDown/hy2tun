# Hy2Tun 1.1.0

Исправлен долгий запуск службы Windows: приложение могло несколько минут показывать
«The Hy2Tun service is not responding» после входа в систему.

- Служба запускается автоматически **без отложенного старта**. Обновление через
  установщик применяет настройку и к существующей установке.
- Окно и значок в трее пытаются запустить остановленную службу. Для этого обычному
  локальному пользователю разрешены только запуск и проверка состояния службы;
  изменение её конфигурации и остановка по-прежнему требуют прав администратора.
- Экран ожидания показывает состояние Windows-службы и ошибку запуска. Добавлена
  кнопка запуска службы (для старых установок при необходимости запрашивает UAC).
- Во время инициализации служба сообщает Windows о прогрессе запуска. Готовность
  интерфейса проверяется отдельно от VPN-подключения и вычисления хеша программы.
- Установщик дожидается состояния RUNNING и сообщает об ошибке запуска вместо
  ложного сообщения об успешной установке. При обновлении конфигурации службы
  используется ожидание её остановки вместо фиксированных пауз и удаления службы.
- В диагностику Windows добавлены настройки отложенного запуска и восстановления,
  а в журнал — время готовности службы.

Windows: исправления службы и интерфейса. macOS и Android: общая версия 1.1.0;
платформенная логика подключения не менялась.

## Скачать

- Windows: `Hy2Tun-1.1.0-setup-windows-amd64.exe` — установщик;
  `Hy2Tun-1.1.0-portable-windows-amd64.zip` — переносная версия.
- macOS: `Hy2Tun-1.1.0-macos-installer.pkg`, `-macos-app.zip`, `-macos-universal.tar.gz`.
- Android: `Hy2Tun-1.1.0-android.apk`.
- Контрольные суммы: `SHA256SUMS-windows.txt`, `SHA256SUMS-macos.txt`, `SHA256SUMS-android.txt`.

Для исправления автозапуска обновите Windows-версию **установщиком**, а не только
заменой exe. Настройки и сохранённые серверы сохраняются.
