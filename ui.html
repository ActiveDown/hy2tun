The list is empty: no app is selected in this mode.

Proxy Russian resources

Off: .ru, .рф, Yandex, VK and Russian IP addresses go direct, bypassing the server, even inside a selected app.

Apps that always go direct

One per line: a process name (windows) or a full path. Their traffic never enters the tunnel, in any mode: remote desktops, your own VPN clients.

Other VPNs go direct

Traffic of WireGuard, OpenVPN and similar clients to their own servers bypasses the tunnel.

DNS leak protection

While the VPN is connected, DNS through the physical adapter (router, ISP) is blocked, so names are resolved only through the tunnel. Needs the service rights.

Exceptions by domain and address

One per line: a domain (example.com, subdomains included), *.ru, an IP or a subnet (10.0.0.0/8). They take priority over apps.

Set up a new server

Use a fresh Ubuntu or Debian server, with root access or passwordless sudo. Point your domain to its IP first. An existing Hysteria2 installation will not be overwritten.

The SSH password is used for this setup and, when saving is enabled, kept only on this device (in the protected app data). A separate VPN password is generated automatically.

Check this SSH fingerprint against your server provider before sending the password.

You can close this window while setup continues. Stopping the task does not undo changes already made on the server.
