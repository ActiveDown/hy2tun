# Hy2Tun 1.0.0

- Развёртывание нового VPN-сервера по SSH прямо из вкладки «Серверы»: адрес, порт,
  логин, пароль, домен и необязательный email сертификата.
- Подтверждение SSH-ключа перед передачей пароля; сохранение публичного ключа и
  проверка при следующих подключениях. Пароль SSH не сохраняется.
- Установка Hysteria2, выпуск и обновление TLS-сертификата, настройка firewall и
  автозапуска. Готовый профиль автоматически добавляется в клиент.
- Этапы установки, отмена и сохранение профиля для восстановления после ошибки
  настройки сертификата или firewall. Проверка VPN с устройства перед подключением.
- Статическая страница Quiet Desk с часами, таймером, задачами и заметками.
  Данные сохраняются только в браузере посетителя; на VPS базы данных нет.
- Для небольших VPS: без полного обновления ОС, с очисткой кэша пакетов и журналом
  Hysteria в оперативной памяти с ограничением 2 МБ.
- Единая версия 1.0.0 для Android, macOS и Windows; воспроизводимая кросс-сборка
  Windows-пакетов с проверкой Wintun и контрольными суммами.

Развёртывание рассчитано на свежие Debian 11+/Ubuntu 20.04+ с IPv4 и systemd 245+.
Требуются root или sudo без пароля, DNS A-запись домена на сервер и доступные
80/TCP, 443/TCP, 443/UDP. Существующая установка Hysteria2 не перезаписывается.
