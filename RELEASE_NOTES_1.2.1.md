# Hy2Tun 1.2.1

Исправлено отображение статистики в админке и добавлено её отключение.

- Нулевой трафик больше не скрывается: у каждого пользователя видны
  `↓ 0 B · ↑ 0 B` и состояние «не в сети», если активных подключений нет.
- Добавлена общая сводка: скачано, отправлено и число VPN-подключений.
  Счётчики обновляются автоматически каждые 15 секунд и по кнопке «Обновить».
- Недоступность Traffic Stats API отличается от нулевого трафика:
  показывается предупреждение, а не выдуманные нули или состояние «не в сети».
- Кнопка «Отключить статистику» удаляет раздел `trafficStats` из конфигурации
  сервера и очищает сохранённые параметры статистики. Пользователи и прочие
  настройки сохраняются. Перед кратким перезапуском запрашивается подтверждение;
  при ошибке применяется прежний механизм отката конфигурации.
- После отключения доступна кнопка включения. Повторное отключение не вызывает
  лишний рестарт службы.
- Добавлены регрессионные тесты API, SSH, конфигурации и отображения счётчиков.

## Скачать

- Windows 1.2.1: `Hy2Tun-1.2.1-setup-windows-amd64.exe` — установщик;
  `Hy2Tun-1.2.1-portable-windows-amd64.zip` — переносная версия.
  Сборки без Authenticode-подписи: возможно предупреждение Windows
  «неизвестный издатель».
- Android 1.2.1: `Hy2Tun-1.2.1-android.apk` — release APK, подписанный прежним
  ключом Hy2Tun, для arm64-v8a, armeabi-v7a и x86_64.
- macOS 1.1.0: прежние установщик, приложение и universal-архив без пересборки
  и изменения содержимого. Новая админка и эти исправления в них отсутствуют.
- Контрольные суммы: `SHA256SUMS.txt` и отдельные файлы для каждой платформы.

Статистика Hysteria хранится в памяти сервера, а не на диске, и сбрасывается
при его перезапуске (в том числе при изменении пользователей или включении/
отключении статистики).
