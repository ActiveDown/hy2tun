# Hy2Tun 1.2.0

Админка Hysteria2 по сохранённому SSH-доступу: пользователи, ссылки подключения
и статистика трафика. Исправлены ошибки первоначальной реализации.

- Устранён сбой при первом прикреплении SSH-доступа, который выглядел как
  «служба недоступна». Исправлены чтение статуса службы и обновление панели.
- Окно открывается сразу, показывает анимацию и этап загрузки. Повторные запросы
  не накапливаются; ответы закрытого окна не меняют новую панель.
- SSH-соединение используется повторно, а таймаут обновляется для каждой команды.
  Ошибки SSH, статистики и локального API отображаются раздельно.
- Link открывает окно ссылки поверх админки; доступны копирование и QR-код.
- Пользователей можно менять и без включённой статистики. Если служба не принимает
  новую конфигурацию, панель восстанавливает предыдущую и перезапускает службу.
- Подтверждение нового SSH-ключа привязано к показанному отпечатку. Файлы
  сохранённых SSH-паролей исключены из Git.
- Добавлены проверки настоящего SSH-протокола и shell-скриптов, включая откат.

Windows и Android пересобираются как 1.2.0. macOS остаётся на прежней сборке
1.1.0 без изменений; новая админка в неё не входит.

Windows: `Hy2Tun-1.2.0-setup-windows-amd64.exe` и
`Hy2Tun-1.2.0-portable-windows-amd64.zip`.
Для обновления Android поверх установленной версии нужен прежний ключ подписи.
Без `android/keystore.properties` сборка создаёт отдельный тестовый debug APK.
