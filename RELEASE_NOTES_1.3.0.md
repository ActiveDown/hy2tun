# Hy2Tun 1.3.0

Обфускация Salamander теперь включается по умолчанию при развёртывании сервера
из клиента: провайдер больше не видит в UDP-потоке узнаваемую сигнатуру Hysteria2.

- При установке сервера через **Servers → Deploy a server** в конфиг
  `/etc/hysteria/config.yaml` добавляется блок `obfs` с типом `salamander`
  и отдельным случайным паролем (24 случайных байта в hex, как и пароль VPN).
- Готовая ссылка профиля сразу содержит `obfs=salamander` и `obfs-password`,
  поэтому подключение работает без ручной правки. Ссылки, выпущенные раньше
  или вручную, остаются обычными и продолжают работать.
- Проверка UDP после установки оборачивает сокет тем же слоем обфускации.
  Раньше такой тест не прошёл бы на сервере с включённым Salamander и выдал бы
  ложное предупреждение.
- Подсказка в окне развёртывания и README описывают новое поведение.
- Серверы, установленные до обновления, не меняются: обфускацию на них можно
  включить вручную, добавив блок `obfs` в конфиг и параметры в ссылку.
- Настройки, серверы и сохранённые SSH-доступы при обновлении сохраняются.

- Windows 1.3.0: `Hy2Tun-1.3.0-setup-windows-amd64.exe` — установщик;
  `Hy2Tun-1.3.0-portable-windows-amd64.zip` — переносная версия.
  Сборки без Authenticode-подписи: возможно предупреждение Windows
  «неизвестный издатель».
- Android 1.2.1: `Hy2Tun-1.2.1-android.apk` — release APK, подписанный прежним
  ключом Hy2Tun, для arm64-v8a, armeabi-v7a и x86_64; без пересборки.
- macOS 1.1.0: `Hy2Tun-1.1.0-macos-installer.pkg`, `Hy2Tun-1.1.0-macos-app.zip`,
  `Hy2Tun-1.1.0-macos-universal.tar.gz` — прежние файлы без пересборки
  и изменения содержимого.
- Контрольные суммы: `SHA256SUMS.txt` и отдельные файлы для каждой платформы.
