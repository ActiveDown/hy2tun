# Hy2Tun 1.2.2

Исправления Windows-клиента: адаптер Wintun больше не получает новый номер при
каждом перезапуске, а IPv6 на туннельном адаптере отключается, когда в сети его нет.

- Адаптер создаётся с постоянным GUID, производным от имени, вместо случайного.
  Windows теперь переиспользует один профиль сети: `Hy2Tun 38`, `Hy2Tun 39`, …
  больше не появляются. Оставшиеся после сбоев адаптеры и старые записи имён
  удаляются перед подключением. Первое подключение после обновления может
  показать прежний номер один раз — дальше он не меняется.
- Если у физической сети нет рабочего IPv6 (адреса и маршрута по умолчанию),
  компонент «IP версии 6 (TCP/IPv6)» на туннельном адаптере отключается, а
  IPv6-адрес и маршруты в туннель не добавляются. В свойствах подключения
  галочка снята, приложения сразу используют IPv4.
- Если IPv6 в сети есть, компонент остаётся включённым и весь v6-трафик
  по-прежнему заводится в туннель — иначе он обходил бы VPN. При смене сети
  состояние переключается автоматически.
- Настройки, серверы и сохранённые SSH-доступы при обновлении сохраняются.
