# Hy2Tun 1.1.1

Исправлено открытие Google, YouTube и других сайтов через Hysteria на серверах
без рабочего выхода в IPv6.

- Если сервер отклоняет TCP-подключение к IPv6-адресу, Hy2Tun повторяет запрос
  по известному имени сайта из TLS SNI, HTTP Host или DNS. Сервер может выбрать
  доступный IPv4-адрес.
- Повтор выполняется до отправки данных приложения. Работающие IPv6-соединения
  сохраняют выбранный приложением адрес; IPv4 и прямые соединения работают как прежде.
- Добавлены регрессионные проверки, включая настоящий Hysteria-сервер с моделью
  IPv4-only выхода и проверкой передачи данных после повторного подключения.

Исправление применяется к TCP-соединениям с известным именем сайта. Для чистых
IPv6-адресов без имени и для UDP по IPv6 серверу по-прежнему требуется выход в IPv6.

- Android 1.1.1: `Hy2Tun-1.1.1-android.apk` — новая сборка с исправлением.
- macOS 1.1.0: `Hy2Tun-1.1.0-macos-installer.pkg`, `-macos-app.zip`,
  `-macos-universal.tar.gz` — прежние файлы из релиза 1.1.0, без пересборки
  и без изменения версии. Исправление 1.1.1 в эти файлы macOS не входит.
- Контрольные суммы: `SHA256SUMS.txt` и отдельные файлы для каждой платформы.
